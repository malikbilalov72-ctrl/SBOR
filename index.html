Установка на iPhone / iPad

  1. Откройте сайт в Safari
  2. Нажмите кнопку «Поделиться» внизу экрана ⬆︎
  3. Выберите «На экран “Домой”»
  4. Нажмите «Добавить»

После этого приложение будет открываться на весь экран и работать без интернета.
